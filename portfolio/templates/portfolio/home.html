02 / Portfolio engineering

This portfolio is an engineering project.

A deployed Django application, not a static résumé page. I use it to put web development, delivery and AI integration into practice.

Application

Django and PostgreSQL power responsive project case studies. Portfolio content is version controlled and synced through an idempotent Django management command.

Testing & delivery

Docker Compose runs the local app. Automated Django tests run in PostgreSQL-backed GitHub Actions CI; feature branches and pull requests lead to Railway deployment with environment-based production configuration.

AI integration

The Google Gemini assistant answers from curated portfolio context and public project records. Its credentials stay server-side.

04 / About

How I got here shapes how I build.

I started my career in professional kitchens, then moved into IT through networking and cybersecurity training. I now work in Cisco Asset Management, where I have built software and automation around operational problems.

That path shapes how I approach a project. I start by learning how the work happens and where people lose time or context. From there, I decide what should be automated, what needs a clearer interface, and where a reliable backend can help. My projects span reporting workflows, document processing, web applications and AI-assisted tools. I am continuing to deepen my software, cloud, automation and infrastructure engineering skills, with a focus on systems that hold up beyond a demo.
